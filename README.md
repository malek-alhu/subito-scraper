# Subito Coin Scraper

A Node.js application that automatically scrapes and monitors coin listings from Subito.it. Built with Nuxt.js, Supabase, and deployed on Vercel.

## Overview

The application scrapes coin listings every 6 hours, stores the data in Supabase, and provides a dashboard to monitor the scraping process and view statistics.

## Tech Stack

- **Frontend**: Nuxt.js
- **Backend**: Node.js
- **Database**: Supabase (PostgreSQL)
- **Deployment**: Vercel
- **Scheduling**: node-cron

## Database Schema

### scraping_sessions
```sql
CREATE TABLE scraping_sessions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL,
  completed_at TIMESTAMP WITH TIME ZONE,
  duration_ms BIGINT DEFAULT 0,
  status TEXT NOT NULL, -- 'completed', 'failed', 'in_progress'
  search_query TEXT NOT NULL,
  total_items INTEGER NOT NULL,
  total_pages INTEGER NOT NULL,
  processed_pages INTEGER DEFAULT 0,
  progress_percentage INTEGER DEFAULT 0,
  error TEXT,
  last_processed_at TIMESTAMP WITH TIME ZONE
);
```

### scraped_items
```sql
CREATE TABLE scraped_items (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  session_id BIGINT REFERENCES scraping_sessions(id),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL,
  item_id TEXT NOT NULL,
  data JSONB NOT NULL,
  UNIQUE(item_id, session_id)
);
```

## Configuration

The scraper can be configured through `server/config/scraper.js`:

```javascript
{
  baseUrl: 'https://hades.subito.it/v1/search/items',
  searchParams: {
    q: 'moneta rara',          // Search query
    itemsPerPage: 100,         // Items per request
    maxConcurrentRequests: 10, // Concurrent requests
    requestDelay: 100,         // Delay between requests (ms)
    batchDelay: 100           // Delay between batches (ms)
  },
  schedule: {
    interval: '0 */6 * * *'    // Runs every 6 hours
  }
}
```

## Workflow

1. **Initialization**
   - Application starts
   - Scheduler initializes
   - First scrape runs immediately
   - Subsequent scrapes scheduled every 6 hours

2. **Scraping Process**
   - Creates new scraping session
   - Fetches total number of items
   - Processes pages in batches of 10
   - Updates progress in real-time
   - Stores results in Supabase

3. **Monitoring**
   - Dashboard shows current status
   - Detailed metrics available
   - Session history tracked
   - Error reporting included

## Environment Setup

1. Clone the repository
2. Create a Supabase project
3. Set up environment variables:
```
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_anon_key
```

4. Install dependencies:
```bash
npm install
```

5. Run development server:
```bash
npm run dev
```

## Deployment

The application is deployed on Vercel:

1. Connect your GitHub repository to Vercel
2. Add environment variables in Vercel dashboard
3. Deploy

## Maintenance

### Session Cleanup
- Failed sessions are automatically marked
- In-progress sessions timeout after 30 minutes
- Manual cleanup available through SQL

### Error Handling
- Failed scrapes are logged
- Sessions marked as failed
- Error messages stored in database

### Monitoring
- Real-time progress tracking
- Success rate monitoring
- Performance metrics
- Session history
